# minimize-shelf

A very light gnome-shell extension that displays the minimized windows of the
current workspace only. They are shown as icons near the wifi, sound etc area.

![Screenshot](/img/screenshot.png?raw=true)

History
============================================================

This is a maintained continuation of
[blfpd/minimize-shelf](https://github.com/blfpd/minimize-shelf), which has not
been updated since December 2022. Thanks to the original authors, Guillaume
Pasquet and Baptiste Darthenay.
